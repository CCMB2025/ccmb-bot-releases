# CCMB Bot releases

Installers for CCMB Bot. The source code is kept elsewhere; this repo holds only finished builds.

- **Windows:** download `CCMB-Bot-<version>-setup.exe` from the newest release and run it. The installed app then updates itself from this page.
- **Android:** download `CCMB-Bot-android-<version>.apk` on the phone and open it. The app checks here for a newer version and offers to download it.
